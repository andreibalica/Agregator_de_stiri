# Agregator de Stiri - Procesare Paralela in Java

Acest proiect este un agregator de stiri care utilizeaza Java Threads pentru a procesa eficient si in paralel un volum mare de articole din fisiere JSON. Programul executa concurent operatii de parsare a datelor, eliminare a duplicatelor, organizare pe categorii/limbi si extragere de statistici.
